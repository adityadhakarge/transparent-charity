# Transparent Charity DApp

A blockchain-based decentralized application designed to make charitable donations more transparent, traceable, and accountable.

The **Transparent Charity DApp** uses Ethereum smart contracts to record donations and manage charity milestones. Donors can contribute funds, monitor charity activities, and participate in milestone voting through their blockchain wallet.

## 🚀 Features

* 🔐 Blockchain-based donation management
* 💰 Secure cryptocurrency donations
* 👛 MetaMask wallet connection
* 📊 Transparent donation statistics
* 🏆 Charity milestone management
* 📎 Evidence submission for milestones
* 🗳️ Donor-based milestone voting
* ⚖️ Weighted voting based on donor contributions
* ✅ 50% quorum requirement for milestone approval
* 💸 Controlled charity withdrawals
* 🔍 On-chain transaction transparency
* 🛡️ Reentrancy protection
* 👤 Owner-based access control

## ⚙️ Prerequisites

Make sure you have installed:

* Node.js
* npm
* MetaMask
* Git

Check Node.js and npm:

```bash
node --version
npm --version
```

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/adityadhakarge/transparent-charity.git
```

Move into the project:

```bash
cd transparent-charity
```

Install backend/blockchain dependencies:

```bash
npm install
```

Install frontend dependencies:

```bash
cd frontend
npm install
cd ..
```

## 🔐 Environment Configuration

Create your local environment file:

```bash
cp .env.example .env
```

Never commit `.env` to GitHub.

The `.env.example` file should contain only placeholder values.

## 🧪 Compile Smart Contract

Run:

```bash
npm run compile
```

You should see the Solidity contract compile successfully.

## 🧪 Run Tests

Run:

```bash
npm test
```

or:

```bash
npx hardhat test
```

The test suite verifies important contract functionality including:

* Contract deployment
* Donations
* Donor tracking
* Milestone creation
* Evidence requirements
* Donor voting
* Quorum validation
* Milestone approval
* Withdrawal functionality

## ⛓️ Run Local Blockchain

Start a local Hardhat blockchain:

```bash
npx hardhat node
```

Keep this terminal running.

Open another terminal and deploy the contract:

```bash
npx hardhat run scripts/deploy.js --network localhost
```

Copy the deployed contract address into the frontend configuration where required.

## 🦊 MetaMask Configuration

For local development, connect MetaMask to the Hardhat local network.

Typical Hardhat settings:

```text
Network Name: Hardhat Local
RPC URL: http://127.0.0.1:8545
Chain ID: 31337
Currency Symbol: ETH
```

Import a test account generated by Hardhat if required.

**Never use a real private key or real funds for local testing.**

## ▶️ Run Frontend

Open a new terminal:

```bash
cd frontend
npm run dev
```

Vite will provide a local development URL, normally similar to:

```text
http://localhost:5173
```

Open the URL in your browser and connect MetaMask.

## 🔒 Smart Contract Security

The smart contract uses OpenZeppelin security components including:

* `Ownable`
* `ReentrancyGuard`

The contract also implements checks for:

* Unauthorized access
* Invalid donations
* Invalid milestone operations
* Duplicate voting
* Missing evidence
* Quorum requirements
* Withdrawal authorization

## 🗳️ Voting System

Milestone approval uses donor voting.

Voting weight is based on the donor's contribution.

A milestone requires the configured quorum before it can be approved.

The current implementation uses a **50% quorum requirement**.

## 💡 Project Objective

Traditional charitable donation systems can make it difficult for donors to independently verify how funds are managed.

This project demonstrates how blockchain can provide:

1. Transparent donation records
2. Tamper-resistant transaction history
3. Publicly verifiable milestone activity
4. Community participation through voting
5. Better accountability for charity fund usage
